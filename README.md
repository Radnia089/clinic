# کلینیک رژیم درمانی تندیس

اپلیکیشن دو‌بخشی برای کلینیک رژیم درمانی تندیس (نسخه ۱.۰.۰):

1. **اپ مشتری** (`/patient`) — معرفی کلینیک و رزرو نوبت
2. **اپ کلینیک** (`/clinic`) — پذیرش منشی + مدیریت + مالی

## جریان پذیرش (منشی)

1. در تقویم روزانه، با کلیک یا کشیدن روی خانه‌ها بازه زمانی شناور (واحد ۱۵ دقیقه) را انتخاب کنید
2. ثبت مراجعه‌کننده: نام، نام‌خانوادگی، سن، جنسیت، موبایل، آدرس + ساعت شروع و مدت نوبت
3. تکمیل فرم پذیرش تخصصی (اندازه‌ها، سابقه، هدف درمان)
4. کنار اسم هر نفر در جدول زمانی، شماره مراجعه (۱، ۲، ۳، ...) دیده می‌شود

## ورود کلینیک

نام کاربری: `tandis` یا `admin` · رمز: `123456`

## اجرا

```bash
npm install
npm run dev -- --port 3847 --hostname 127.0.0.1
```

سپس باز کنید: [http://127.0.0.1:3847](http://127.0.0.1:3847)

داده‌ها به‌صورت محلی در `.data/clinic-app.json` ذخیره می‌شوند.

ساعات کاری پیش‌فرض: ۸ تا ۲۱ با واحد ۱۵ دقیقه (ویزیت ۳۰ دقیقه، پکیج/دستگاه ۶۰ دقیقه).

## مسیرها

| مسیر | توضیح |
| --- | --- |
| `/` | انتخاب اپ مشتری یا کلینیک |
| `/patient` | اپ مشتری |
| `/login` | ورود منشی/مدیر |
| `/clinic` | داشبورد مدیریت |
| `/clinic/reception` | میز پذیرش (تقویم شناور) |
| `/clinic/reception/new` | ثبت مراجعه‌کننده |
| `/clinic/reception/customers` | لیست مشتریان |
| `/clinic/reception/visitors` | جدول مراجعه‌کنندگان |
| `/clinic/reception/admitted` | جدول پذیرش‌شده‌ها |
| `/clinic/finance` | پرداخت‌ها |
| `/clinic/appointments` | نوبت‌های آنلاین |

## پشته

Next.js · TypeScript · Tailwind CSS · shadcn/ui
