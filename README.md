# کلینیک رژیم درمانی تندیس

اپلیکیشن دو‌بخشی برای کلینیک رژیم درمانی تندیس (نسخه ۱.۰.۰):

1. **اپ مشتری** (`/patient`) — معرفی کلینیک و رزرو نوبت
2. **اپ کلینیک** (`/clinic`) — پذیرش منشی + مدیریت + مالی + پیامک یادآوری

## جریان پذیرش (منشی)

1. در تقویم روزانه، با کلیک یا کشیدن روی خانه‌ها بازه زمانی شناور (واحد ۱۵ دقیقه) را انتخاب کنید
2. ثبت مراجعه‌کننده: نام، نام‌خانوادگی، سن، جنسیت، موبایل، آدرس + ساعت شروع و مدت نوبت
3. تکمیل فرم پذیرش تخصصی (اندازه‌ها، سابقه، هدف درمان)
4. کنار اسم هر نفر در جدول زمانی، شماره مراجعه (۱، ۲، ۳، ...) دیده می‌شود

## پیامک یادآوری نوبت

مسیر: `/clinic/reminders`

- **صبح روز نوبت** (ساعت قابل تنظیم، پیش‌فرض ۸ صبح به‌وقت ایران)
- **چند ساعت قبل از نوبت** (پیش‌فرض ۳ ساعت)
- قالب پیام قابل ویرایش با متغیرهای `{name} {date} {time} {clinic} {type}`
- بدون تنظیم: حالت **آزمایشی (Mock)** — پیام‌ها فقط در لاگ ذخیره می‌شوند
- با **گوشی اندروید** (اپ [SMS Gateway](https://docs.sms-gate.app/)): ارسال از سیم‌کارت همان گوشی
- با کلید **کاوه‌نگار**: ارسال از پنل پیامک

اولویت خودکار: اندروید → کاوه‌نگار → Mock

متغیرهای پیامک را در `.env` طبق `.env.example` تنظیم کنید (اندروید یا کاوه‌نگار).

روی گوشی (اگر از اندروید استفاده می‌کنید): اپ را باز بگذارید، اینترنت روشن باشد، دسترسی SMS بدهید. از صفحه یادآوری «ارسال آزمایشی» را بزنید.

سرویس هر دقیقه صف را چک می‌کند. اجرای دستی و ارسال آزمایشی از همان صفحه ممکن است.

برای cron خارجی:

```bash
curl -X POST http://127.0.0.1:3847/api/reminders \
  -H 'Content-Type: application/json' \
  -d '{"action":"run"}'
```

## نوتیفیکیشن صندوق اپ مشتری (Web Push)

وقتی از پنل کلینیک (`/clinic/notifications`) پیام به صندوق مشتری ارسال شود، در صورت فعال بودن نوتیف روی گوشی، حتی با اپ بسته هم اعلان می‌آید.

```bash
# یک‌بار کلید بسازید و در .env بگذارید
npx web-push generate-vapid-keys
NEXT_PUBLIC_VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:info@tandisclinicyazd.ir
```

مشتری بعد از ورود در صفحه اصلی دکمه «فعال کردن» را می‌زند و اجازه نوتیفیکیشن می‌دهد. برای iOS معمولاً باید سایت را به Home Screen اضافه کند. تست لوکال بهتر است با HTTPS باشد (`next dev --experimental-https`).

## ورود

از دکمه **ورود** در هدر لندینگ، نقش را انتخاب کنید:

- مشتری → `/patient/login`
- کارکنان → `/login?next=/clinic/reception`
- مدیریت → `/login?next=/clinic`

### دو مسیر مشتری

1. **مراجع حضوری:** با ثبت پرونده در پذیرش، پیامک خوشامد + لینک اپ ارسال می‌شود (`kind: welcome`).
2. **نصب مستقیم اپ:** کاربر ثبت‌نام می‌کند، اطلاعات تکمیلی را پر می‌کند، و در پنل **ثبت‌نام اپ** (`/clinic/app-signups`) دیده می‌شود.

## اجرا

```bash
cp .env.example .env   # در صورت نیاز
npm install
npm run db:setup       # migrate + seed (SQLite)
npm run dev -- --port 3847 --hostname 127.0.0.1
```

سپس باز کنید: [http://127.0.0.1:3847](http://127.0.0.1:3847)

### دیتابیس

- **SQLite** با **Prisma** در مسیر `.data/clinic.db` (`DATABASE_URL=file:./.data/clinic.db`)
- جداول: مشتریان، ویزیت، پرداخت، نوبت، مشاوره آنلاین، اندازه‌گیری، پیامک، قهرمانان، بنر، مجله، صندوق پیام، پشتیبانی، تنظیمات کلینیک، کاربران کارکنان
- با اولین اجرا، داده‌های پیش‌فرض (مقالات، قهرمانان، بنر، کاربران کارکنان) و در صورت وجود، مهاجرت از `.data/clinic-app.json` انجام می‌شود
- دستورها: `npm run db:migrate` · `npm run db:seed` · `npm run db:setup`

ساعات کاری پیش‌فرض: ۸ تا ۲۱ با واحد ۱۵ دقیقه (ویزیت ۳۰ دقیقه، پکیج/دستگاه ۶۰ دقیقه).
